# Проверка публичной поставки Q2

Дата: 25 октября 2026 года. Этот документ относится к подготовленной папке репозитория, а не подтверждает публикацию на GitHub.

## Среда

- Windows, Python 3.14.7.
- Streamlit 1.66.1, Pillow 13.0.0, pytesseract 0.3.13 — соответствуют `requirements.txt`.
- Tesseract 5.5.3.20260724 с языками `rus` и `eng`.
- Использовано существующее локальное окружение Q2. Чистая установка на другом компьютере, Python 3.12/3.13 и облачный хостинг в этой проверке не тестировались.

## Результаты

`python -m unittest discover -s tests -v` завершился с кодом 0: **78 тестов, ошибок нет, один пропуск**. Пропуск относится к классу проверок частных изображений: эти файлы намеренно не распространяются. Проверки логики, интерфейса Streamlit и OCR на искусственных изображениях выполнены.

`python quality_check.py` завершился с кодом 0. Из 15 искусственных случаев 13 дали ожидаемый результат. В двух заранее обозначенных сложных случаях (`wrong_tiny`, `wrong_low_contrast`) вместо выявления расхождения текст не найден. Эти случаи **не считаются успешным распознаванием**. Серия допускает такие пропуски трудных примеров; поэтому нулевой код завершения не означает 100% точность. На остальных случаях не обнаружены ошибочные уверенные совпадения или ложные расхождения. Это ограниченная регрессия, а не оценка качества на всех карточках.

Сервер Streamlit запущен локально на временном тестовом порту; его проверка готовности вернула `ok`. После проверки тестовый сервер остановлен. Интерфейс дополнительно проверен через Streamlit AppTest. Двойной щелчок по `start.bat` и установка библиотек с нуля в этой поставке отдельно не повторялись; сохранён исходный сценарий запуска Q2.

## Состав и очистка

- Основные исходники приложения и OCR, файл версии, `requirements.txt` и `start.bat` сверены с найденной Q2: содержимое сохранено.
- Все 24 PNG повторно сгенерированы предоставленными скриптами; SHA-256 совпали с распространяемыми изображениями. Это искусственные примеры, а не фотографии клиентов. Файлы шрифтов не включены.
- Настоящие карточки, старые OCR-отчёты, история предыдущих сборок, окружения, кэши и временные файлы не копировались.
- Тест частных изображений теперь явно пропускается при их отсутствии. `run_tests.bat` проверяет публичный набор и не требует частной карточки.
- Выполнен поиск распространённых форматов токенов, закрытых ключей и личных путей в распространяемых текстовых файлах; совпадений не найдено. Это не универсальная гарантия обнаружения всех возможных секретов.
- Проверено, что Git игнорирует `.env`, `.streamlit/secrets.toml`, частные изображения, пользовательские загрузки, отчёты и `.venv`. Ручная загрузка через сайт GitHub этих правил не применяет.

README, `.gitignore`, `.gitattributes`, инструкция происхождения примеров и этот отчёт подготовлены для публичной поставки. Лицензия не выбрана. Репозиторий на GitHub и публичный веб-сервис автоматически не создавались.
